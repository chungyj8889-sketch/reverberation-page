# 잔향 — 부재의 울림

전시 《잔향 — 부재의 울림》의 SNS 사전 홍보용 관람 수칙 티저입니다. 인스타그램 게시물, 스토리, 프로필 링크에서 GitHub Pages URL로 연결해 관객이 규칙과 여운만 남기고 나가도록 구성했습니다.

## GitHub Pages 배포

1. 이 폴더의 파일을 새 GitHub 저장소 루트에 업로드합니다.
2. GitHub 저장소에서 `Settings` → `Pages`로 이동합니다.
3. `Build and deployment`의 Source를 `Deploy from a branch`로 설정합니다.
4. Branch는 `main`, folder는 `/root`를 선택한 뒤 저장합니다.
5. 발급된 Pages URL을 PPT의 홍보 전략 슬라이드에 첨부합니다.

## 구성

- `index.html`: 관람 수칙 중심 페이지 구조
- `styles.css`: 포스터 기반 시각 시스템과 잔향 클릭 효과
- `script.js`: 규칙 카드 선택 상태, 스크롤 진행 표시, 잔향 효과
- `assets/`: 배경 텍스처와 PPT 기반 섹션 이미지

공개 저장소로 배포할 경우 PPT에서 가져온 작품 이미지는 출처 표기 또는 대체 이미지 검토를 권장합니다.
